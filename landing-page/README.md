# IncidentGuard — BSV landing page

Static, single-file landing page for the BSV track (TUM Blockchain & AI Hackathon 2026, team pavLex).

- Open `index.html` in a browser. No build step and no dependencies (only Google Fonts).
- Colours match the architecture diagram palette (night navy, neon indigo #5049E8, lavender #8F98F0, ember #F0A050 for the Growth Pool only). Accent colours are CSS variables at the top of the file.
- `[PRICE]` and the footer `#` links are placeholders.
- Design source: the "IncidentGuard landing page" design on claude.ai.
