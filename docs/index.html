Quick start

Every investigation follows the same three calls. One payment buys exactly one report — a payment can never be reused.

# 1. ask for a quote
POST /v1/quote        { "question": "...", "tier": "guardrail" }
# 2. pay it from the agent's BRC-100 wallet, then submit the transaction
POST /v1/pay          { "quote_id": "q_…", "tx": "<raw tx hex>" }
# 3. collect the report
GET  /v1/report/{request_id}

Base URL: [API_BASE_URL]. All bodies are JSON.

Authentication

Register your agent in the Agents & API page of the portal to get an API key. Send it on every request:

Authorization: Bearer ig_live_[YOUR_KEY]

An API key identifies the agent and its budget. It never grants access to evidence on its own — paying and seeing are separate permissions.

POST/v1/quote

Returns a fixed price bound to a new request ID. Quotes are valid for 10 minutes.

FieldTypeDescription
questionstringWhat you want investigated, in plain language.
tierstringguardrail (everyday checks) or pentest_pro (authorised targets only).
scopeobjectRequired for pentest_pro: { "target": "staging.example.com", "authorised": true }.
// 200 OK
{
  "quote_id": "q_8c21…",
  "request_id": "req_7f3a91c2",
  "price": { "amount": "[PRICE]", "currency": "BSV" },
  "pay_to": "[PAYMENT_ADDRESS_OR_SCRIPT]",
  "expires_at": "2026-10-31T12:10:00Z"
}

POST/v1/pay

Submit the signed BSV transaction that pays the quote. The portal checks that the amount matches, binds the payment to the request, and rejects any transaction that was already used.

// request
{ "quote_id": "q_8c21…", "tx": "<raw tx hex>" }

// 202 Accepted
{ "request_id": "req_7f3a91c2", "status": "verifying" }

GET/v1/report/{request_id}

Poll until status is delivered. Every finding links to a citation, and limitations are always stated.

{
  "request_id": "req_7f3a91c2",
  "status": "delivered",
  "tier": "guardrail",
  "findings": [
    { "severity": "high", "text": "Pattern matches credential stuffing…", "citations": [1, 2] }
  ],
  "citations": [ { "id": 1, "title": "[SOURCE TITLE]", "url": "…" } ],
  "limitations": "Based only on the log excerpt provided.",
  "payment_tx": "3c9e…a41b",
  "report_hash": "sha256:…"
}

Agent budgets

Each agent has a daily spending cap and a list of tiers it may buy. A quote that would exceed the cap is refused before any payment. Approved agents can also draw capped credit from the non-custodial Growth Pool.

Errors

CodeMeaning

409 payment_reusedThis transaction already paid for another request.

429 budget_exceededThe agent's daily cap would be exceeded.
